# 실험 결과 해석

표는 [README.md](README.md) (스크립트가 자동 생성). 이 문서는 사람이 읽고 판단하기 위한 해석이다.

## 일관되게 나타난 것 (3건 모두)
- **환경변수 사용**: 사양서 없음 0/3 → 사양서 있음 3/3
- **입력 검증**: 0/3 → 3/3
- **파일 분리**: 평균 3개 → 약 11개. 한 파일에 몰아 쓰지 않고 책임별로 나눔 (유지보수 규칙의 폴더 구조·파일 크기 제한이 반영된 결과)

## 차이가 작거나 없던 것
- **AI가 임의로 정한 것**: 4·4·5 → 3·4·4. 줄긴 했지만 폭이 작고, 모델의 자기 보고라 신뢰도가 낮다
- **비밀번호 해시**: 양쪽 모두 0. 세 요청 모두 추천안이 "이메일 로그인"이 아니어서 해당 규칙이 켜지지 않았다 (규칙이 꺼진 상태에서 나온 결과이므로 효과 판단 불가)

## 기대와 다른 것
- **출력 토큰은 줄지 않았다** (≈4.7k→5.0k, 6.5k→6.7k, 6.8k→5.1k). 사양서는 첫 시도의 출력량을 줄이지 않는다
- 따라서 "토큰 절약"을 주장하려면 첫 시도가 아니라 **다시 요청하는 횟수**(재작업)를 재야 한다. 이 실험은 그걸 재지 않았다

## 발표에서 할 수 있는 말 / 하면 안 되는 말
- 할 수 있음: "같은 요청에 사양서를 붙이면 보안 기본기(키 분리·입력 검증)와 구조 분리가 3건 모두에서 지켜졌다"
- 하면 안 됨: "토큰이 N% 줄었다" — 측정된 근거 없음
